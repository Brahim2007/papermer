# بروتوكول تقييم الصلة المستقل

يقيّم كل مقيّم جميع المرشحين في ملفه بصورة مستقلة. لا يطّلع على اسم طريقة
الاسترجاع أو رتبتها أو درجات المقيّم الآخر، ولا يناقش الحالات قبل تسليم الملف.

## مقياس الصلة

- `2` — صلة مباشرة: الورقة تجيب حاجة الاستعلام بوضوح أو تقدم طريقة/نتيجة مركزية لها.
- `1` — صلة جزئية: الورقة مفيدة للسياق أو لمكوّن فرعي، لكنها لا تعالج الحاجة كاملة.
- `0` — غير ذات صلة: التشابه سطحي، أو المجال مختلف، أو لا تقدم محتوى مفيدًا للحاجة.

يُملأ `confidence` بقيمة `1` أو `2` أو `3`، حيث `3` ثقة عالية. يُكتب
`rationale` عند الثقة المنخفضة أو عندما يعتمد الحكم على تمييز دقيق. لا تُترك أي
قيمة relevance فارغة، ولا تُغيّر المعرفات أو النصوص أو ترتيب الصفوف.

بعد استلام الملفين، تحسب الأداة الاتفاق وتنتج ملف adjudication. الحالات المتفق
عليها تُقفل آليًا، أما التعارضات فيحسمها مقيّم ثالث أو جلسة تحكيم موثقة مع كتابة
`adjudication_rationale`. لا يُستخدم تصويت نموذج لغوي كحكم ثالث.
